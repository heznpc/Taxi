# Changelog

All notable Taxi changes are recorded here from version 1.0.0 onward.

## 1.0.0 — Unreleased

- Add bounded execution history/export, Modore snapshot references, provider capture/review and recovery, Chrome structured debugging, and an optional Windows PAD request/callback adapter.
- Correct MCP instructions and preserve per-invocation request evidence through audit history.

- Establish the independent Taxi product, package, CLI, app, filesystem,
  transport, and security identities.
- Define the canonical `setup`, `run`, `connect`, `doctor`, `verify`,
  `modules`, and `workflows` command surface.
- Ship standard modules in the root npm and MCPB artifacts without external
  add-on package installation.
- Provide a self-contained macOS app runtime with ownership and token
  attestation.
- Preserve the MIT license, source provenance, and third-party notices.
